# 在线采购使用方式

自 README「在线采购使用方式」一节原文迁移（2026-10-31），内容未改动。平台接入实施细节见 [接入实施计划](shopping-integration-plan.md)，手机选购实验见 [手机实验步骤和验收表](shopping-cart-experiment.md)。

在「食材库存」点击「去采购」，勾选待购食材、核对数量并创建采购任务。在「平台入口」粘贴自己取得的官方 HTTPS 购物链接，先在实际设备测试，再勾选确认保存。未配置入口时仍可复制清单自行购买。

打开链接或扫码只打开平台，不自动传入清单、加购物车、下单或付款。购买完成后勾选任务条目记录已下单；收货时上传商品清单图片、粘贴文字或手工填写实收项，核对后确认入库。图片会发送到已配置的视觉模型。未收货的采购项不会进入可用库存。

默认新增独立批次。选择合并库存时，仅相同名称和存放位置的可用食材可合并，克/千克等明确单位可以换算；盒、包、把等规格需要填写核对后的总数量。勾选“已收齐”后才核销原待购条目；少送和分批到货保留未完成需求。

第二阶段新增淘宝闪购联盟附近门店查询和官方购买链接。自行取得联盟应用 API 权限与渠道 PID 后，在本机 `.env` 填写 `TAOBAO_UNION_APP_KEY`、`TAOBAO_UNION_APP_SECRET`、`TAOBAO_UNION_PID` 并重启服务。在「官方门店查询」输入门店关键词和经地图核对的 GCJ-02 经纬度，确认发送位置后查询，再获取门店链接或二维码。

结果包含来源、查询时间、起送价、配送费和平台推荐商品价格（如平台返回）；规格和配送范围需自行核对。结果缓存 5 分钟，购买链接展示和缓存最多 2 分钟；该时限是本应用刷新策略，不是平台承诺的有效期。密钥不会进入页面或模型；经纬度只发送至平台，不写入本地候选缓存。

配置凭证不代表开通权限，成功查询后才显示接口已验证。淘宝接口检索门店名称，无法代替食材全站搜索；美团待取得官方联盟签名 SDK 和实际供给权限，目前保留手动入口。自动加购、平台订单同步尚未接入。当前没有本机联盟凭证，真实平台与手机跳转验收仍待完成。详情见 [接入实施计划](shopping-integration-plan.md)。

第三阶段新增「手机选购实验」：选择淘宝闪购采购任务后，可记录原购物车、核对至多三项商品规格、计算补购件数、逐步登记手机操作并比较购物车差异。未知结果和异常差异会停止后续步骤。当前手机搜索和加购由本人完成，尚未连接自动控制；实验不会自动结算或标记任务已下单。详见 [手机实验步骤和验收表](shopping-cart-experiment.md)。
