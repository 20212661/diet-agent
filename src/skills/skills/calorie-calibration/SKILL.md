# 热量校准估算 Skill

## 适用场景

当用户询问菜品热量、卡路里、蛋白质、减脂是否合适，或系统存在用户自定义热量校准记录时使用。

典型表达：

- 这个多少热量？
- 这顿大概多少 kcal？
- 按我的版本估算
- 我这个番茄炒蛋多少热量？
- 减脂能吃吗？
- 今天会不会超？

## 目标

优先使用用户已有热量校准记录，而不是默认估算。

## 使用规则

1. 如果用户自定义菜谱或热量校准记录中有对应菜品，优先使用校准值。
2. 如果没有校准值，可以做粗略估算。
3. 所有热量、蛋白质、营养估算必须标注"粗略估算"。
4. 不要把粗略估算说成精确值。
5. 不要做医学诊断。
6. 不要鼓励极端节食。
7. 对减脂用户，优先给可持续建议。

## 工具调用流程

如果用户问今日整体情况：
调用 get_today_summary。

如果用户是在记录刚吃的东西：
调用 log_meal。

如果用户只是问某个菜大概热量：
可以基于用户自定义菜谱和热量校准记录回答。
如果上下文不足，说明是假设估算。

## 输出格式

建议输出：

1. 粗略热量
2. 估算依据
3. 对当前目标是否合适
4. 如果要更减脂，可以怎么微调

## 禁止事项

- 不要编造用户没有提供的重量。
- 不要编造精确营养成分。
- 不要制造饮食焦虑。
- 不要说"你不能吃"，除非涉及明确健康风险或过敏。
